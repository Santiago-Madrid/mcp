# Servidor MCP con Herramientas Matemáticas y Microservicios

## 🚀 Características

- **4 Herramientas Matemáticas**: Suma, multiplicación, división, potenciación
- **2 Herramientas de Microservicio**: Consulta de usuarios y publicaciones
- **Transporte HTTP**: Fácil integración con clientes MCP
- **Manejo de errores**: Casos de éxito y error manejados
- **Pruebas completas**: 9 casos de prueba exitosos
